## 第一层：法律（全国人大制定，强制执行）

### 《中华人民共和国个人信息保护法》（PIPL）

| 项目 | 内容 |
|------|------|
| 施行日期 | 2021年11月1日 |
| 核心条款 | 第28-32条（敏感个人信息处理规则） |
| 关键要求 | 生物特征信息属于敏感个人信息；处理需取得个人单独同意；需具有特定目的和充分必要性；需进行个人信息保护影响评估 |

### 《中华人民共和国数据安全法》（DSL）

| 项目 | 内容 |
|------|------|
| 施行日期 | 2021年9月1日 |
| 核心条款 | 第21条（数据分类分级）、第25条（数据出境安全评估） |
| 关键要求 | 视频监控含生物特征数据需纳入数据分类分级管理；重要数据出境须经安全评估 |

### 《中华人民共和国网络安全法》

| 项目 | 内容 |
|------|------|
| 施行日期 | 2017年6月1日 |
| 核心条款 | 第21条（网络安全等级保护制度）、第37条（境内存储） |
| 关键要求 | 视频监控系统需落实等保要求；关键信息基础设施运营者在境内收集的个人信息和重要数据应在境内存储 |

### 《中华人民共和国民法典》

| 项目 | 内容 |
|------|------|
| 施行日期 | 2021年1月1日 |
| 核心条款 | 第1034-1039条（隐私权和个人信息保护） |
| 关键要求 | 不得非法收集、使用、加工、传输他人个人信息；不得非法买卖、提供或者公开他人个人信息 |

## 关于《中华人民共和国计量法》

### 结论：基本不直接适用于生物特征识别系统

计量法（1985年制定，2018年修正）的调整对象是"计量器具"——即能用以直接或间接测出被测对象量值的装置、仪器仪表、量具和标准物质。如温度计、电能表、加油机、出租车计价器等列入《强制检定的工作计量器具目录》的设备。

生物特征识别系统的核心功能是"身份识别"而非"量值测量"，通常不纳入计量器具范畴。但以下情况例外：
- 系统中集成了列入强制检定目录的硬件设备（如特定传感器）
- 涉及司法鉴定用途时，相关设备可能需要校准溯源

**更应关注的法律法规**是《个人信息保护法》、《数据安全法》以及上述列出的各项国家标准，它们对生物特征数据的收集、存储、使用、删除有直接且具体的规范要求。
