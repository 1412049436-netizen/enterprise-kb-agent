## 一、通用安全生产法规

### 核心法律

| 文件 | 说明 |
|------|------|
| 《中华人民共和国安全生产法》（2021修正） | 安全生产基本法，第36条要求设置报警装置 |
| 《中华人民共和国消防法》（2021修正） | 火灾报警系统法律依据 |
| 《生产安全事故报告和调查处理条例》（国务院令第493号） | 事故分级与报告要求 |

### 安全生产标准化

| 标准号 | 名称 | 说明 |
|--------|------|------|
| GB/T 33000-2016 | 企业安全生产标准化基本规范 | 安全生产标准化通用要求 |
| GB 45673-2025 | 危险化学品企业安全生产标准化通用规范 | 2025.11.01实施，强制性国标 |
| AQ/T 9009-2015 | 生产安全事故应急演练评估规范 | 报警响应演练 |

> 注：GB 45673-2025 适用于危化品企业，对于 GPU/电子制造企业，GB/T 33000 更为适用。

## 四、GPU/显卡制造车间专项

### 洁净室环境监控

| 项目 | 标准/参考 | 典型阈值 |
|------|----------|----------|
| 温度 | GB 50073 洁净厂房设计规范 | 22±2°C |
| 湿度 | GB 50073 | 45±10% RH |
| 颗粒度 | ISO 14644-1 | Class 100~10000 |
| ESD 静电 | ANSI/ESD S20.20 | < 100V |

### 设备报警（GPU 生产设备）

| 设备类型 | 监控项 | 报警阈值 |
|----------|--------|----------|
| 贴片机（SMT） | 气压、温度、进料异常 | 即时停机报警 |
| 回流焊炉 | 炉温、链速、氮气流量 | 偏差 ±5°C 告警 |
| AOI 光学检测 | 缺陷率 | >1% 触发返工 |
| 老化测试（Burn-in） | GPU温度、功耗、时钟 | 温度 > 85°C 告警 |

### GPU 测试/运维报警（nvidia-smi 相关）

| 告警类型 | 监控命令 | 参考阈值 |
|----------|----------|----------|
| GPU 温度过高 | `nvidia-smi -q -d TEMPERATURE` | > 85°C 告警，> 95°C 紧急 |
| GPU 功耗异常 | `nvidia-smi -q -d POWER` | 超过 TDP 的 110% |
| 显存 ECC 错误 | `nvidia-smi -q -d ECC` | 单比特纠错 > 1000/天告警 |
| GPU 掉卡 | `nvidia-smi -L` | 设备列表减少即告警 |
| PCIe 降速 | `nvidia-smi -q -d PCI` | Gen < 预期值告警 |
| 风扇故障 | `nvidia-smi -q -d FAN` | 转速=0 或 RPM < 最小值 |
| GPU 利用率异常 | `nvidia-smi -q -d UTILIZATION` | 持续 100% 或持续 0% |

参考文件：
- 《GPU 机房运维实战手册》（社区整理资料）
- NVIDIA DCGM（Data Center GPU Manager）官方文档：https://docs.nvidia.com/datacenter/dcgm/

## 五、报警分级与响应

### 三级报警体系

| 级别 | 定义 | 响应时间 | 处理流程 |
|------|------|----------|----------|
| 一级（红色） | 火灾/爆炸/有毒气体泄漏 | 立即响应 | 全厂疏散 + 119 |
| 二级（橙色） | 设备故障可能导致停产 | ≤ 5 分钟 | 值班工程师到场 |
| 三级（黄色） | 参数偏差预警 | ≤ 30 分钟 | 远程排查或巡检 |

### 报警记录要求

根据 GB/T 33000-2016 和 GB 50523：

- 报警发生时间、解除时间记录
- 报警原因分析与处理措施
- 报警阈值变更审批记录
- 定期（至少每季度）报警统计分析报告
