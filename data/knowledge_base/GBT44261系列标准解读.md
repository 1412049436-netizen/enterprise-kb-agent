# GB/T 44261 系列标准解读

## 概述

GB/T 44261《信息技术 生物特征识别技术在视频监控系统中的应用》是推荐性国家标准系列，采标自 ISO/IEC 30137。该系列目前国内已发布 2 部分（第1部分和第4部分），第2、第3部分尚未发布。

归口单位：全国信息技术标准化技术委员会（SAC/TC 28）生物特征识别分技术委员会（SC 41）

## 已发布标准

### GB/T 44261.1-2024 第1部分：系统设计和规范

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 44261.1-2024 |
| 英文名 | Information technology — Use of biometrics in video surveillance systems — Part 1: System design and specification |
| 发布日期 | 2024-07-24 |
| 实施日期 | 2025-02-01 |
| 是否采标 | 是（ISO/IEC 30137-1） |
| 状态 | 现行 |
| 类别 | 推荐性国家标准（推标） |
| ICS分类 | 35_信息技术、办公机械 |

**适用范围**：规定了在视频监控系统中使用生物特征识别技术的系统设计原则、架构要求、性能指标和规范。适用于新建或改造的视频监控系统中集成生物特征识别功能的设计、开发和部署。

### GB/T 44261.4-2024 第4部分：真值与视频标注程序

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 44261.4-2024 |
| 英文名 | Information technology — Use of biometrics in video surveillance systems — Part 4: Ground truth and video annotation procedure |
| 发布日期 | 2024-10-26 |
| 实施日期 | 2025-05-01 |
| 是否采标 | 是（ISO/IEC 30137-4） |
| 状态 | 现行 |
| 类别 | 推荐性国家标准（推标） |

**适用范围**：规定了用于评估生物特征识别系统性能的真值（Ground Truth）建立方法和视频数据标注程序，适用于系统测试、性能评估和算法训练。

## 合规要点

1. **推荐性标准不等于没有约束力**：在政府采购、项目验收、司法鉴定等场景中，推荐性标准可作为技术依据
2. **与人脸识别法规联动**：系统设计需同时满足 GB/T 44261.1 的技术规范和 GB/T 41819-2022《人脸识别数据安全要求》的安全要求
3. **与个人信息保护法衔接**：系统设计阶段就应考虑数据最小化、目的限定、单独同意等 PIPL 要求
